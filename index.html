Trigger

Configuration Fields

The config screen has three tabs: Rules (shown below), Statuses (define valid status values), and Actions (define available action buttons). Category selector at top-left: Applications / Change Requests / etc. Rules are evaluated top to bottom — the first match wins, so rule order is precedence. A rule with no conditions always matches, meaning anything below it never runs.

→ Set status → More Info Required
IF

Action is Decline

IF

Statuses tab: Defines the valid status values that appear in the Worklist Status column. Each status has a label, colour indicator, and whether it counts as a terminal state (closed). Statuses cannot be applied directly — they are set via IF→THEN rule outcomes.

Actions tab: Defines the action buttons that appear in the worklist Actions column for each item. Each action has a label and a key that is referenced in IF→THEN rule conditions. Examples: Assign, Approve, Decline, Request Info, Complete.

Trigger
